# Governance references for Saudi Arabia

This folder is reserved for notes you add later from official Saudi government or regulator publications.

MVP 1 does not store any regulatory requirements here, and it does not load any into the database.

Do not add guessed legal text. When a source is reviewed, store it in the `governance_references` table of the Saudi Arabia database with:

- jurisdiction
- authority
- regulation or reference
- requirement
- applicability
- source URL
- date verified
- implementation status
- technical control mapping

Silsilah does not provide legal advice and does not certify compliance.
